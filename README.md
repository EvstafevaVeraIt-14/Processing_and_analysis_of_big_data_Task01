# Дисциплина "Искусственный интеллект и большие данные (Обработка и анализ больших данных)". Работа 1.

**Выполнили:** Евстафьева Вера и Окулова Александра.

**ATUS 2024: сон и бюджет времени**

**Исследовательский вопрос:** Как различается продолжительность сна в будни и выходные у работающих взрослых в США?

**План исследования:** загрузка и проверка данных → объединение таблиц → отбор работающих взрослых → описательная статистика → сравнение по полу, возрасту и типу занятости → дни недели → сон и рабочая активность → бюджет времени → вывод.

Сравниваются **разные респонденты**: каждый участник заполнил только один дневник. Результаты являются описательными, без сложных статистических тестов.

**Данные:** `atussum_2024.csv` и `atusresp_2024.csv`.

**Охват:** США; один дневник суток на респондента. Summary и Respondents описывают одних и тех же 7669 человек. Будние и выходные представлены разными респондентами.

**Основные поля:** TUCASEID — идентификатор; TUFINLWGT — итоговый вес; TUDIARYDAY — день недели дневника; TEAGE — возраст; TESEX — пол; t010101 — время сна в минутах; остальные tXXXXXX — время по видам деятельности.

**Примечания:** Источник загрузки — открытое зеркало Hugging Face LongDA с зафиксированной ревизией. Официальный сервер BLS отвечал 403. Побайтовое совпадение с BLS не подтверждено. Репликатные веса не получены: комплект позволяет описательный анализ; для корректных популяционных ДИ нужен дополнительный файл весов и методика ATUS.
